## Bell County Foreclosure Case Research

### Odyssey Case Search Workflow

1. Click each entity's **Search** link above to open Odyssey with the search term pre-filled
2. Click **Submit** on the Odyssey page
3. Record the following for each result:

### Data to Capture Per Entity

- Number of cases returned
- Case numbers
- Filing dates
- Plaintiff (trustee/servicer)
- Defendant (property owner)
- Property address
- Assigned judge / court
- Case status (Active / Disposed)
- Disposition type
- Appeal filed? (case number, court, outcome)
