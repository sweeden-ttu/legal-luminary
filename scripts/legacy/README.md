# Legacy — do not run

`generate_dossiers.py` and `generate_dossiers_remaining.py` wrote the 2026-06-09 "dossier" text into every judge
profile from hard-coded strings with no research and no sources ("J.D., accredited law school", generic docket
descriptions, invented memberships). Every profile was re-verified against public sources on 2026-11-03 and the
unsourced text removed. These scripts are kept only as a record of where that text came from. Running them would
overwrite verified profiles with unsourced boilerplate.
